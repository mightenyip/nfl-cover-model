# Weekly Model Performance Files

Individual week performance analysis files.

Each file contains:
- Game-by-game predictions from each model
- Actual results
- Correct/incorrect predictions for each model
- Consensus predictions and accuracy

## File Naming Convention

- `week{X}_model_performance.csv` - Performance analysis for Week X

## Columns

Typical columns include:
- `game` - Game matchup
- `actual_cover` - Whether underdog actually covered
- `model_a_pred`, `model_b_pred`, etc. - Prediction from each model
- `model_a_correct`, `model_b_correct`, etc. - Whether each model was correct
- `consensus_pred`, `consensus_correct` - Consensus prediction and accuracy
